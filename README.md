# CakeBake 🍰

CakeBake is an ASP.NET Core MVC e-commerce web application for a bakery.  
It allows customers to browse products, manage their cart, place orders, and manage their accounts, while providing an admin dashboard for managing products, categories, and orders.

---

## Features

### Customer
- User Registration & Login
- Email Verification with OTP
- Forgot / Reset Password
- Browse Products
- Search & Filter Products
- Shopping Cart
- Checkout
- Order History
- User Profile Management
- Contact Us

### Admin
- Dashboard
- Manage Products
- Manage Categories
- Manage Customers
- Manage Orders
- Manage Contact Messages
- Profile Settings
